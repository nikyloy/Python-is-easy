## О проекте

Цель PythonLocker — сделать изучение Python последовательным и удобным: пользователь читает объяснение, выполняет практическое задание и запускает своё решение прямо из приложения.

Материалы уроков хранятся отдельно от C#-кода в JSON-файле. Такой подход позволяет редактировать теорию и задания, не переписывая логику интерфейса.

### Для кого предназначен проект

- Для начинающих изучать Python.
- Для тех, кто хочет закреплять теорию практическими заданиями.
- Для разработчиков, которым интересны C#, WinForms и запуск внешних процессов.

## Возможности

### Реализуется в проекте

- **Обучающий интерфейс Windows Forms** с отдельными окнами и переходами между разделами.
- **Уроки из JSON** — текст учебных материалов отделён от логики приложения.
- **Практические задания** с полем для ввода Python-кода.
- **Запуск Python-кода** через установленный интерпретатор Python.
- **Проверка результата** выполнения задания по ожидаемому выводу.
- **Последовательная структура урока**: объяснение, задания и ожидаемый результат.

### Запланировано или зависит от текущей версии

- Сохранение прогресса и продолжение обучения с последнего места.
- Более развитая система проверки ответов и сообщений об ошибках.
- Светлая и тёмная темы.
- Улучшенная адаптивная прокрутка длинных уроков.
- Дополнительные уроки, тесты и задания.
- Завершённый визуальный стиль и набор графических ресурсов.

Перечисление в этом разделе не означает, что каждая функция уже полностью готова.

## Требования

Перед запуском подготовьте:

1. Компьютер под управлением Windows.
2. Visual Studio с компонентом разработки классических приложений .NET (Desktop development with .NET).
3. Установленный Python 3.
4. Доступный исполняемый файл Python — команда `python` должна работать в командной строке, либо в настройках приложения должен быть указан полный путь к `python.exe`.

Проверьте Python в командной строке:

```bat
python --version
```

Если команда не найдена, установите Python и включите добавление Python в `PATH` либо настройте путь к интерпретатору вручную.

**Версия .NET:** используйте целевую платформу, указанную в файле проекта `.csproj`. Если проект переносится на другую машину, сначала проверьте совместимость WinForms и используемых API. Например, `System.Text.Json` входит в современные версии .NET, но может потребовать отдельного пакета или изменения настроек в старом проекте .NET Framework.

## Установка и запуск

### Через Visual Studio

1. Скачайте или клонируйте репозиторий.
2. Откройте файл решения `.sln` в Visual Studio. Если решения нет, откройте файл проекта `.csproj`.
3. Проверьте целевую версию .NET в свойствах проекта.
4. Убедитесь, что файл `texts.json` присутствует в проекте и доступен приложению во время запуска.
5. Убедитесь, что Python установлен и запускается командой `python --version`.
6. Восстановите NuGet-пакеты, если Visual Studio предложит это сделать.
7. Соберите проект: **Build → Build Solution**.
8. Запустите приложение клавишей **F5** или **Ctrl+F5**.

### Важно про пути к файлам

Не рекомендуется хранить путь к `texts.json` в виде абсолютного адреса конкретного компьютера, например:

```csharp
@"C:\Users\Asus\source\repos\PythonLocker\PythonLocker\texts.json"
```

На другом компьютере такого пути может не быть. Надёжнее размещать JSON рядом с исполняемым файлом или в отдельной папке данных и формировать путь относительно каталога приложения. В Visual Studio также проверьте свойства `texts.json`: при необходимости настройте копирование файла в выходной каталог (`Copy to Output Directory`).

Пример получения пути к файлу рядом с приложением:

```csharp
string jsonPath = Path.Combine(
    AppDomain.CurrentDomain.BaseDirectory,
    "texts.json"
);

string json = File.ReadAllText(jsonPath);
```

Этот пример подходит, если файл действительно копируется в каталог приложения. Для старых целевых платформ и иных схем размещения путь нужно проверить отдельно.

## Структура проекта

Фактические имена файлов могут меняться по мере разработки. Ожидаемая логическая структура выглядит примерно так:

```text
PythonLocker/
├── PythonLocker.sln
├── PythonLocker/
│   ├── PythonLocker.csproj
│   ├── Program.cs
│   ├── MainMenu.cs
│   ├── MainMenu.Designer.cs
│   ├── LearningPart.cs
│   ├── LearningPart.Designer.cs
│   ├── Part1_learning.cs
│   ├── Part1_learning.Designer.cs
│   ├── Form1.cs
│   ├── Form1.Designer.cs
│   ├── texts.json
│   └── Resources/
└── README.md
```

Назначение основных частей:

- **`Program.cs`** — точка входа приложения.
- **`MainMenu`** — главное меню и переход к обучению.
- **`LearningPart`** — раздел выбора или продолжения обучения.
- **`Part1_learning`** — окно отображения учебного материала.
- **`Form1`** — форма практического задания и проверки кода; точное назначение зависит от актуальной реализации.
- **`texts.json`** — тексты уроков, заголовки, порядок блоков и данные для заданий.
- **`Resources/`** — изображения, текстуры, значки и другие ресурсы, если они используются.

Это пример организации, а не гарантированный список файлов текущей сборки.

## Как устроены уроки

Учебные материалы хранятся в `texts.json`. Структура урока может включать заголовок и массив групп. Каждая группа содержит идентификатор, название и ключ, по которому приложение получает текст из словаря материалов.

Упрощённый пример:

```json
{
  "lesson_0": {
    "title": "УРОК 0. ЗНАКОМСТВО С PYTHON",
    "groups": [
      {
        "id": 1,
        "title": "Знакомство с Python",
        "text_key": "main_text_1"
      },
      {
        "id": 2,
        "title": "Практическое задание",
        "text_key": "test_part_1"
      }
    ]
  },
  "main_text_1": "Здесь находится текст объяснения.",
  "test_part_1": "Здесь находится условие задания."
}
```

Это только иллюстрация формата: фактические ключи и обязательные поля должны соответствовать JSON и C#-коду текущей версии.

### Добавление нового урока

1. Откройте `texts.json`.
2. Создайте новый объект урока с уникальным ключом, например `lesson_2`.
3. Укажите заголовок и группы в требуемом порядке.
4. Добавьте тексты, на которые ссылаются поля `text_key`.
5. Если у задания есть проверка результата, добавьте и настройте соответствующие данные ожидаемого вывода согласно формату, который использует проверяющая форма.
6. Проверьте корректность JSON: запятые, кавычки, скобки и уникальность ключей.
7. Запустите приложение и пройдите урок от начала до конца.

**Совет:** храните учебный текст и логику проверки раздельно. Не добавляйте в JSON C#-код и не меняйте названия ключей, пока не проверили, что на них ссылается приложение.

## Как работает проверка Python-кода

Общая схема запуска, используемая в проекте:

1. Пользователь вводит код в поле редактора.
2. Приложение сохраняет код во временный файл с расширением `.py`.
3. C# запускает внешний процесс Python.
4. Приложение получает стандартный вывод (`stdout`) и сообщения об ошибках (`stderr`).
5. Полученный результат сравнивается с ожидаемым выводом задания, если для задания настроена такая проверка.
6. Пользователь получает результат выполнения или сообщение об ошибке.

Для запуска внешнего процесса обычно используется `System.Diagnostics.Process` и `ProcessStartInfo`. Перенаправление потоков вывода позволяет показывать результат в приложении, не открывая отдельное консольное окно.

Проверка по ожидаемому выводу требует заранее определить правила сравнения: например, учитывать ли завершающий перевод строки, лишние пробелы и различия между `stdout` и `stderr`. Эти правила должны быть единообразными для всех заданий.

## Настройка и разработка

### Рекомендации по структуре кода

- Отделяйте интерфейс формы от логики загрузки уроков и проверки решений.
- Не дублируйте путь к `texts.json` в нескольких формах.
- Проверяйте существование файлов и обрабатывайте ошибки чтения JSON.
- Показывайте ученику понятные сообщения об ошибках, не скрывая полезный диагностический вывод.
- Используйте уникальные идентификаторы уроков и заданий.
- Сохраняйте прогресс только после определения стабильного формата данных и поведения при повреждённом файле сохранения.
- Проверяйте длинные тексты на разных размерах окна и при включённой прокрутке.

### Работа с JSON

При чтении JSON учитывайте целевую версию .NET и доступные API. Если компилятор не распознаёт `JsonDocument`, сначала проверьте:

- подключена ли библиотека `System.Text.Json`;
- поддерживает ли её целевая платформа;
- установлен ли необходимый NuGet-пакет;
- не использует ли проект старую версию .NET Framework.

Не меняйте весь способ чтения JSON до проверки причины ошибки компиляции.

## Решение типичных проблем

### Приложение не находит `texts.json`

- Проверьте, что файл добавлен в проект.
- Проверьте его расположение относительно исполняемого файла.
- Убедитесь, что файл копируется в выходной каталог при сборке.
- Не используйте путь, привязанный к имени пользователя на одном компьютере.

### Команда `python` не найдена

- Проверьте установку Python командой `python --version`.
- Проверьте переменную среды `PATH`.
- При необходимости укажите полный путь к `python.exe` в настройках приложения.

### Не запускается `System.Text.Json` или не распознаётся `JsonDocument`

- Посмотрите целевую платформу проекта в `.csproj`.
- Проверьте ссылку на сборку или NuGet-пакет `System.Text.Json`.
- Убедитесь, что версия пакета совместима с целевой платформой.
- После изменения зависимостей восстановите пакеты и пересоберите проект.

### Окно не возвращается к главному меню

Проверьте логику переходов между формами: какая форма скрывается, какая открывается и что происходит при закрытии дочернего окна. Избегайте создания нескольких экземпляров главного меню без необходимости.

### Результат задания не совпадает с ожидаемым

- Проверьте, что в ожидаемом выводе нет лишних символов.
- Посмотрите реальные `stdout` и `stderr`.
- Проверьте правила обработки переводов строк и пробелов.
- Убедитесь, что приложение запускает нужный интерпретатор и правильный временный файл.

## Безопасность

PythonLocker запускает код, введённый пользователем, через установленный интерпретатор Python. Такой код может обращаться к файлам, запускать процессы и выполнять другие действия с правами текущего пользователя.

**Запуск Python-кода нельзя считать безопасным только потому, что он выполняется из учебного приложения.** Не запускайте неизвестные или недоверенные программы. Если приложение планируется распространять среди других пользователей, изолированный запуск, ограничения доступа и контроль времени выполнения следует спроектировать отдельно. Простое скрытие консольного окна или сохранение скрипта во временный файл не являются песочницей.
