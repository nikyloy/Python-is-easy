# PythonLocker

**PythonLocker** — настольное приложение для изучения языка программирования Python. Оно создаётся на **C#** с использованием **Windows Forms (WinForms)**. В приложении пользователь читает теорию, выполняет практические задания и запускает свой Python-код.

> **Статус проекта:** проект находится в разработке. Некоторые функции могут работать не полностью или отличаться от описания. Инструкция ниже рассчитана на человека, который впервые устанавливает Python и Visual Studio.

## О проекте

Цель PythonLocker — сделать изучение Python последовательным и удобным. Пользователь читает объяснение, выполняет практическое задание и запускает решение прямо из приложения.

Тексты уроков и часть структуры обучения хранятся отдельно от C#-кода в JSON-файле. Благодаря этому учебные материалы можно редактировать, не переписывая логику интерфейса.

### Для кого предназначен проект

- Для тех, кто только начинает изучать Python.
- Для тех, кто хочет закреплять теорию практическими заданиями.
- Для тех, кому интересны C#, Windows Forms и создание обучающих приложений.

## Возможности

### Уже реализуется в проекте

- Интерфейс Windows Forms с отдельными окнами и переходами между разделами.
- Загрузка учебных материалов из JSON.
- Теоретические блоки и практические задания.
- Поле для ввода Python-кода.
- Запуск введённого кода через установленный на компьютере Python.
- Получение результата выполнения и сообщений об ошибках.
- Проверка результата по ожидаемому выводу задания.

### Запланировано или зависит от версии проекта

- Сохранение прогресса и продолжение обучения с последнего места.
- Более развитая проверка ответов и обработка ошибок.
- Светлая и тёмная темы.
- Улучшенная прокрутка длинных уроков.
- Дополнительные уроки, тесты и задания.
- Завершённый визуальный стиль и набор графических ресурсов.

Наличие функции в этом списке не означает, что она уже полностью реализована.

Для запуска проекта из исходного кода нужен компьютер с Windows и две программы:

## 1. Установка Python

PythonLocker запускает Python-код с помощью интерпретатора, установленного отдельно от самого приложения. Поэтому сначала установите Python.

### Шаг 1. Откройте официальный сайт

Перейдите на официальный сайт Python:

**https://www.python.org/downloads/windows/**

Скачивайте Python только с официального сайта или из Microsoft Store. Не используйте случайные сайты с установщиками.

### Шаг 2. Скачайте установщик

На странице выберите актуальный стабильный вариант Python для Windows. Для большинства современных компьютеров подходит версия **64-bit (x86-64)**.

Если сайт предлагает сначала установить **Python Install Manager**, скачайте и установите его, следуя подсказкам на экране. После этого установите стабильную версию Python через менеджер, если он попросит выбрать или установить среду выполнения.

### Шаг 3. Установите Python

1. Откройте скачанный файл из папки **Загрузки (Downloads)**.
2. Если Windows спросит разрешение на запуск установщика, подтвердите запуск.
3. Следуйте инструкциям установщика.
4. Если появится настройка добавления Python в `PATH` или предложение добавить команды Python в переменные среды, включите её.
5. Нажмите кнопку установки — обычно она называется **Install** или **Install Now**.
6. Дождитесь завершения установки.

`PATH` — это список папок, в которых Windows ищет программы по их короткому имени. Благодаря этой настройке PythonLocker сможет запускать Python командой `python`, не зная полного адреса программы.

Если установщик не показывает настройку `PATH`, не переживайте: после установки просто выполните проверку из следующего раздела. Если команда не найдётся, воспользуйтесь разделом [«Команда python не найдена»](#команда-python-не-найдена).

## 2. Проверка, что Python установлен

Теперь проверим, что Windows действительно видит Python.

### Шаг 1. Откройте командную строку

1. Нажмите клавиши `Win + R`.
2. В появившемся небольшом окне напишите `cmd`.
3. Нажмите `Enter`.

Откроется чёрное окно — это командная строка Windows. В неё можно вводить команды.

### Шаг 2. Введите команду проверки

Скопируйте или напишите:

```bat
python --version
```

Нажмите `Enter`.

Если всё установлено правильно, Windows покажет номер версии, например:

```text
Python 3.x.x
```

Цифры могут отличаться — это нормально.

### Шаг 3. Проверьте запуск простого кода

В той же командной строке введите:

```bat
python -c "print('Python работает!')"
```

Должно появиться:

```text
Python работает!
```

Если обе команды сработали, Python установлен и доступен через команду `python`.

Если Windows пишет, что команда не найдена, перейдите к разделу [«Команда python не найдена»](#команда-python-не-найдена).

## 3. Установка Visual Studio

Теперь установим программу, в которой находится исходный код PythonLocker.

### Шаг 1. Откройте официальный сайт Visual Studio

Перейдите на страницу загрузки:

**https://visualstudio.microsoft.com/ru/downloads/**

Найдите **Visual Studio Community** и нажмите кнопку бесплатной загрузки.

> Не скачивайте Visual Studio Code вместо Visual Studio. Это другой редактор, и для открытия данного WinForms-проекта он не подходит.

### Шаг 2. Запустите установщик

1. Откройте скачанный файл из папки **Загрузки (Downloads)**.
2. Если Windows запросит разрешение, нажмите **Да**.
3. Дождитесь запуска установщика Visual Studio.
4. Если появится предложение обновить установщик, согласитесь.

### Шаг 3. Выберите нужный компонент

В установщике появится список рабочих нагрузок (Workloads). Это наборы инструментов для разных типов программ.

Найдите и обязательно отметьте:

**«Разработка классических приложений .NET»**  
(английское название — **.NET desktop development**).

Именно этот компонент нужен для создания программ на C# с Windows Forms.

Необязательно выбирать остальные компоненты: для обычного запуска PythonLocker они не нужны, если сам проект не требует дополнительных инструментов.

### Шаг 4. Установите Visual Studio

1. Убедитесь, что выбран компонент **.NET desktop development**.
2. Нажмите **Install / Установить**.
3. Дождитесь окончания загрузки и установки. Это может занять некоторое время.
4. Если установщик попросит перезагрузить компьютер, выполните перезагрузку.

После установки откройте **Visual Studio** через меню «Пуск».

## 5. Открытие проекта в Visual Studio

### Шаг 1. Найдите файл проекта

Откройте папку, в которую вы распаковали PythonLocker.

Найдите файл решения с расширением `.sln`. Он может называться, например, `PythonLocker.sln`.

- Если файл `.sln` есть — откройте его.
- Если файла `.sln` нет — найдите файл проекта с расширением `.csproj` и откройте его.

Файл `.sln` объединяет проект или несколько проектов в одном решении. Файл `.csproj` содержит настройки конкретного C#-проекта.

### Шаг 2. Откройте решение

Есть два удобных способа:

**Способ А:**

1. Дважды щёлкните по файлу `.sln`.
2. Если Windows спросит, какой программой открыть файл, выберите Visual Studio.

**Способ Б:**

1. Запустите Visual Studio.
2. На стартовом экране нажмите **Open a project or solution / Открыть проект или решение**.
3. Перейдите в папку PythonLocker.
4. Выберите файл `.sln` или `.csproj`.
5. Нажмите **Open / Открыть**.

Подождите, пока Visual Studio загрузит проект.

### Шаг 3. Дождитесь восстановления компонентов

При первом открытии Visual Studio может загружать или восстанавливать NuGet-пакеты. Это дополнительные библиотеки, которые могут понадобиться проекту.

Если появится предложение восстановить пакеты, согласитесь. Дождитесь окончания процесса.

### Шаг 4. Проверьте файл с уроками

В проекте используется файл `texts.json` с текстами и структурой уроков.

Убедитесь, что он присутствует в файлах проекта. Если приложение позже сообщит, что не может найти `texts.json`, смотрите раздел [«Программа не находит texts.json»](#программа-не-находит-textsjson).

## 6. Сборка и запуск программы

Когда проект открыт, можно собрать и запустить приложение.

### Шаг 1. Соберите проект

В верхнем меню Visual Studio:

1. Откройте пункт **Build / Сборка**.
2. Выберите **Build Solution / Собрать решение**.
3. Подождите, пока Visual Studio завершит сборку.

В нижней части окна появится результат сборки.

- **Build succeeded / Сборка успешно выполнена** — ошибок сборки нет, можно запускать программу.
- **Build failed / Сборка завершилась с ошибками** — программа пока не собрана. Откройте список ошибок (Error List / Список ошибок), чтобы посмотреть причину.

### Шаг 2. Запустите PythonLocker

Есть два варианта:

- Нажмите `F5`, чтобы запустить программу с отладкой.
- Нажмите `Ctrl + F5`, чтобы запустить программу без отладки.

После этого должно открыться главное окно PythonLocker.

### Шаг 3. Проверьте работу Python внутри приложения

1. Перейдите к практическому заданию.
2. Введите простой код:

   ```python
   print("Привет из Python!")
   ```

3. Нажмите кнопку запуска или проверки кода в приложении.
4. Если всё настроено правильно, приложение должно показать результат выполнения.

Если приложение не может запустить Python, сначала проверьте команду `python --version` в командной строке Windows.

## Структура проекта

Фактические имена файлов могут отличаться. Ниже приведён пример логической структуры:

```text
PythonLocker/
├── PythonLocker.sln
├── PythonLocker/
│   ├── PythonLocker.csproj
│   ├── Program.cs
│   ├── MainMenu.cs
│   ├── MainMenu.Designer.cs
│   ├── LearningPart.cs
│   ├── LearningPart.Designer.cs
│   ├── Part1_learning.cs
│   ├── Part1_learning.Designer.cs
│   ├── Form1.cs
│   ├── Form1.Designer.cs
│   ├── texts.json
│   └── Resources/
└── README.md
```

Назначение основных частей:

- **`Program.cs`** — точка входа, с которой начинается запуск приложения.
- **`MainMenu`** — главное меню.
- **`LearningPart`** — раздел выбора или продолжения обучения.
- **`Part1_learning`** — окно с учебным материалом.
- **`Form1`** — форма практического задания и проверки кода; точное назначение зависит от текущей реализации.
- **`texts.json`** — тексты уроков, заголовки, порядок блоков и данные заданий.
- **`Resources/`** — изображения, текстуры, значки и другие ресурсы, если они используются.

Это пример организации, а не гарантированный список файлов текущей версии.

## Как устроены уроки

Учебные материалы хранятся в `texts.json`. Структура урока может включать заголовок и массив групп. Каждая группа содержит идентификатор, название и ключ, по которому приложение получает текст.

Упрощённый пример:

```json
{
  "lesson_0": {
    "title": "УРОК 0. ЗНАКОМСТВО С PYTHON",
    "groups": [
      {
        "id": 1,
        "title": "Знакомство с Python",
        "text_key": "main_text_1"
      },
      {
        "id": 2,
        "title": "Практическое задание",
        "text_key": "test_part_1"
      }
    ]
  },
  "main_text_1": "Здесь находится текст объяснения.",
  "test_part_1": "Здесь находится условие задания."
}
```

Это иллюстрация формата. Фактические ключи и обязательные поля должны соответствовать JSON и C#-коду текущей версии.

### Добавление нового урока

1. Откройте `texts.json`.
2. Создайте новый объект урока с уникальным ключом, например `lesson_2`.
3. Укажите заголовок и группы в нужном порядке.
4. Добавьте тексты, на которые ссылаются поля `text_key`.
5. Если у задания есть проверка результата, добавьте ожидаемый вывод в формате, который использует проверяющая форма.
6. Проверьте корректность JSON: кавычки, запятые и скобки.
7. Запустите приложение и пройдите урок.

Не меняйте названия ключей, пока не проверили, что на них ссылается C#-код.

## Как работает запуск Python-кода

Общая схема работы:

1. Пользователь вводит код в поле редактора.
2. Приложение сохраняет код во временный файл с расширением `.py`.
3. C# запускает внешний процесс Python.
4. Приложение получает обычный вывод программы (`stdout`) и сообщения об ошибках (`stderr`).
5. Если для задания задан ожидаемый вывод, приложение сравнивает его с полученным результатом.
6. Пользователь видит результат или сообщение об ошибке.

Для запуска внешней программы используется механизм `System.Diagnostics.Process` и настройки `ProcessStartInfo`.

## Если что-то не работает

### Команда `python` не найдена

**Что это означает:** Windows не может найти установленный интерпретатор по команде `python`.

Что попробовать:

1. Закройте командную строку и откройте её заново.
2. Повторите команду `python --version`.
3. Если проблема осталась, проверьте, что Python действительно установлен.
4. Если установщик предлагал добавить Python в `PATH`, но этот пункт не был выбран, запустите установщик повторно и включите соответствующую настройку, если она доступна.
5. Если используется Python Install Manager, следуйте его подсказкам по настройке команд и `PATH`.

После изменения `PATH` откройте новое окно командной строки и повторите проверку.

### При вводе `python` открывается Microsoft Store

Windows может использовать системный псевдоним команды вместо установленного интерпретатора.

1. Убедитесь, что Python установлен.
2. Откройте параметры Windows и найдите **Псевдонимы выполнения приложений (App execution aliases)**.
3. Проверьте записи `python.exe` и `python3.exe`.
4. Если они перехватывают команду, отключите соответствующие псевдонимы и проверьте Python снова.

Если вы не уверены, какие записи менять, сначала проверьте установку Python и обратитесь к официальной документации.

### Visual Studio не предлагает открыть проект

- Убедитесь, что вы распаковали ZIP-архив, а не открываете файлы внутри архива.
- Найдите файл `.sln` или `.csproj`.
- Если таких файлов нет, возможно, вы открыли не ту папку или скачали не ту часть репозитория.

### Не удаётся собрать проект

- Убедитесь, что в Visual Studio установлена рабочая нагрузка **.NET desktop development**.
- Дождитесь восстановления NuGet-пакетов.
- Посмотрите вкладку **Error List / Список ошибок**.
- Проверьте целевую платформу проекта в файле `.csproj`. Версия .NET SDK или целевая платформа должны быть совместимы с проектом.

Не пытайтесь исправлять все ошибки одновременно: сначала разберите первую ошибку в списке.

### Программа не находит `texts.json`

- Проверьте, что `texts.json` есть в проекте.
- Проверьте, куда Visual Studio копирует этот файл при сборке.
- Если в свойствах файла доступен параметр **Copy to Output Directory / Копировать в выходной каталог**, настройте копирование в соответствии с логикой проекта.
- Не используйте абсолютный путь, привязанный к папке пользователя на одном компьютере.

Приложение должно искать JSON по пути, который существует и на других компьютерах, например относительно папки запуска программы.

### Python установлен, но PythonLocker его не запускает

1. Откройте командную строку.
2. Выполните `python --version`.
3. Если команда работает, полностью закройте PythonLocker и запустите его снова из Visual Studio.
4. Если ошибка осталась, проверьте, какую команду или путь к `python.exe` использует код приложения.

### Результат задания не совпадает с ожидаемым

- Проверьте сам код и ожидаемый вывод.
- Посмотрите сообщения `stdout` и `stderr`.
- Проверьте лишние пробелы и переносы строк.
- Убедитесь, что запускается нужный Python и правильный временный файл.

## Безопасность

PythonLocker запускает код, введённый пользователем, через установленный интерпретатор Python. Такой код может обращаться к файлам и выполнять действия с правами текущего пользователя.

**Не запускайте неизвестный или недоверенный код.** Запуск из учебного приложения сам по себе не делает программу безопасной. Скрытие консольного окна и сохранение скрипта во временный файл не являются изоляцией. Если проект будет распространяться среди других пользователей, ограничения и безопасную изоляцию запуска нужно проектировать отдельно.
