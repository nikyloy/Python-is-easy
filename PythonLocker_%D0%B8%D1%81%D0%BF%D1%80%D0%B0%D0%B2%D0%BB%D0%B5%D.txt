============================================================ УРОК 0.
ЗНАКОМСТВО С PYTHON
============================================================

ЦЕЛЬ Понять, что такое язык программирования, для чего нужен Python и
как выглядит простая программа.

1.  ЧТО ТАКОЕ ПРОГРАММИРОВАНИЕ?

Программирование — это запись инструкций, которые компьютер должен
выполнить. Компьютер не угадывает намерения человека: инструкции нужно
записать достаточно точно.

Например, мы хотим сложить два числа и показать результат:

a = 5 b = 7 print(a + b)

Результат: 12

Здесь a = 5 связывает имя a со значением 5, b = 7 — имя b со значением
7, а print(a + b) вычисляет сумму и выводит её.

2.  ЧТО ТАКОЕ PYTHON?

Python — язык программирования общего назначения. Его используют для
автоматизации задач, веб-разработки, анализа данных, научных вычислений
и создания приложений. Он популярен среди новичков, потому что многие
конструкции читаются сравнительно легко.

print(“Привет, мир!”)

Команда print() выводит информацию. Текст записывают в кавычках.

3.  КАК ЗАПУСКАЕТСЯ PYTHON?

Для выполнения Python-кода нужен интерпретатор — программа, которая
запускает код. В распространённой реализации CPython исходный код
сначала преобразуется в байт-код, а затем выполняется виртуальной
машиной Python. Поэтому фраза «Python выполняет каждую строку напрямую»
— упрощение.

Для начала достаточно понимать процесс: 1. Человек пишет код. 2.
Интерпретатор Python запускает его. 3. Программа показывает результат
или сообщение об ошибке.

PythonLocker, написанный на C#, может сохранять введённый код в файл,
запускать установленный Python и показывать вывод. Самому C# не
обязательно реализовывать язык Python.

ДАННЫЕ, ПЕРЕМЕННЫЕ И ТИПЫ
============================================================

ЦЕЛЬ Научиться хранить значения в переменных и различать основные типы
данных.

1.  ПЕРЕМЕННЫЕ

Переменная — это имя, связанное со значением. Её можно представить как
подпись, по которой программа обращается к данным.

age = 15 name = “Alex”

Здесь age связано с целым числом 15, а name — со строкой “Alex”. Знак =
в Python обычно выполняет присваивание, а не проверяет математическое
равенство.

Имена переменных могут содержать буквы, цифры и подчёркивание, но не
должны начинаться с цифры. Хорошие имена обычно объясняют назначение
значения: user_name, score, is_ready.

2.  ОСНОВНЫЕ ТИПЫ

int — целые числа: age = 15 score = 100

float — числа с дробной частью. Используется точка: price = 19.5
temperature = 24.0

str — текст: name = “Alex” message = ‘Привет!’

bool — логическое значение True или False: is_ready = True has_key =
False

list — упорядоченный изменяемый список: numbers = [1, 2, 3]
numbers.append(4)

tuple — упорядоченный набор, который обычно не меняют: point = (10, 20)

dict — словарь пар «ключ: значение»: player = {“name”: “Alex”, “level”:
3} print(player[“name”])

set — множество уникальных элементов: unique_numbers = {1, 2, 2, 3}

None — специальное значение, которое часто означает отсутствие значения.
Его тип называется NoneType: result = None

На первом этапе важнее всего уверенно понимать int, float, str и bool.
Остальные типы достаточно узнавать и понимать их основную идею.

3.  КАК УЗНАТЬ ТИП?

Функция type() возвращает тип значения:

print(type(10)) print(type(2.5)) print(type(“hello”)) print(type(True))

4.  ПРЕОБРАЗОВАНИЕ ТИПОВ

number_text = “25” number = int(number_text) print(number + 5)

Результат: 30.

int() пытается преобразовать значение в целое число, float() — в
дробное, str() — в строку. Преобразование может завершиться ошибкой:
например, int(“привет”) не сможет превратить слово в число.

5.  КОНСТАНТЫ

В Python обычную переменную нельзя сделать неизменяемой одним лишь
написанием имени. Но по соглашению имена значений, которые программист
не планирует менять, пишут заглавными буквами:

MAX_SCORE = 100 PI_APPROXIMATION = 3.14

Это соглашение, а не строгий запрет языка.

age = int(input(“Сколько тебе лет?”)) print(“Через год тебе будет”,

Если пользователь введёт текст вместо числа, int() завершится ошибкой.

УСЛОВИЯ И ЛОГИКА

ЦЕЛЬ Научиться выполнять разные действия в зависимости от условия.

1.  if

Условия позволяют программе принимать решения. Например, можно
проверить, разрешён ли доступ пользователю.

age = 18 if age >= 18: print(“Доступ разрешён”)

После условия ставится двоеточие, а команда внутри блока записывается с
отступом.

2.  if, elif И else

score = 75

if score >= 90: print(“Отлично”) elif score >= 60: print(“Зачёт”) else:
print(“Нужно повторить тему”)

Условия проверяются сверху вниз. Выполняется первая подходящая ветка.
elif добавляет дополнительную проверку, а else задаёт действие, если
предыдущие условия не сработали.

3.  ОПЕРАТОРЫ СРАВНЕНИЯ

== равно != не равно > больше < меньше >= больше или равно <= меньше или
равно

Не путай = и ==. Первый присваивает значение, второй сравнивает
значения.

password = “python123” if password == “python123”: print(“Пароль
принят”)

4.  ЛОГИЧЕСКИЕ ОПЕРАТОРЫ

and — все соединённые условия должны быть истинными. or — достаточно
одного истинного условия. not — меняет логическое значение на
противоположное.

age = 16 has_permission = True

if age >= 16 and has_permission: print(“Можно продолжить”)

============================================================ УРОК 4.
ЦИКЛЫ ============================================================

ЦЕЛЬ Научиться повторять действия и правильно останавливать цикл.

1.  ЗАЧЕМ НУЖНЫ ЦИКЛЫ?

Если нужно вывести много чисел, неудобно писать отдельную команду
print() для каждого. Цикл позволяет повторять инструкции.

2.  ЦИКЛ for И range()

for number in range(1, 6): print(number)

Будут выведены числа 1, 2, 3, 4, 5. Правая граница range() не
включается.

for i in range(5): print(“Привет”)

Здесь цикл повторится пять раз, а i получит значения 0, 1, 2, 3, 4.

3.  ЦИКЛ while

count = 1 while count <= 3: print(count) count += 1

count += 1 означает count = count + 1. Переменная изменяется, поэтому
условие со временем станет ложным и цикл закончится. Если забыть
предусмотреть остановку, цикл может выполняться бесконечно.

4.  break

break немедленно завершает ближайший цикл.

while True: command = input(“Введите exit для выхода:”) if command ==
“exit”: break print(“Вы ввели:”, command)

while True сам по себе не завершится, пока не произойдёт break или
другая причина остановки.

5.  ЕСТЬ ЛИ В PYTHON do-while?

В Python нет отдельного цикла с синтаксисом do-while. Похожее поведение
можно получить через while True и break, если тело нужно выполнить хотя
бы один раз. В этом уроке достаточно понимать саму идею.

3.  МЕТОД init

Метод init вызывается при создании объекта и задаёт начальные значения.

class Product: def init(self, product_id, name, price): self.product_id
= product_id self.name = name self.price = price

class Product: def init(self, product_id, name, price): self.product_id
= product_id self.name = name self.price = price

    def get_info(self):
        return f"[{self.product_id}] {self.name} — {self.price:.2f} руб."

product = Product(1, “Книга”, 12.5) print(product.get_info())

Результат: [1] Книга — 12.50 руб.

f-строка позволяет вставлять значения внутрь строки. Формат :.2f
показывает число с двумя цифрами после десятичной точки.

6.  КЛАСС Catalog

class Catalog: def init(self): self.products = []

    def add_product(self, product):
        self.products.append(product)

    def display_catalog(self):
        for product in self.products:
            print(product.get_info())

Пример использования:

catalog = Catalog() catalog.add_product(Product(1, “Книга”, 12.5))
catalog.add_product(Product(2, “Ручка”, 2.0)) catalog.display_catalog()

Catalog хранит список товаров. add_product() добавляет товар, а
display_catalog() проходит по списку и выводит информацию о каждом
товаре.
